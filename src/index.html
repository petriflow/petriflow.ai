Petriflow MCP Server

Model Context Protocol server exposing Petriflow to AI tools

Streamable HTTP transport Apache-2.0

About

This server implements the Model Context Protocol for Petriflow, letting MCP-compatible AI tools call Petriflow functionality as tools, read Petriflow data as resources, and reuse ready-made prompts — all over a single HTTP endpoint. It's built with xmcp.

Status: early scaffold — the tools, prompts, and resources listed below are placeholder examples from the project template. Real Petriflow functionality is still being implemented.

Server details

MCP endpoint
http://localhost:3001/mcp
Transport
Streamable HTTP (stateless)
Health check
GET http://localhost:3001/health

These URLs are filled in automatically from wherever this page is served, assuming the default /mcp endpoint. Update the path below if you've customized it in xmcp.config.ts.

Connect from an AI tool

Claude Code (CLI)

Register the server with the Claude Code CLI:

claude mcp add --transport http petriflow http://localhost:3001/mcp
Claude Desktop

Add a custom connector in Settings → Connectors, or add this entry to your config file:

{
  "mcpServers": {
    "petriflow": {
      "url": "http://localhost:3001/mcp"
    }
  }
}
Cursor

Add to ~/.cursor/mcp.json (or your project's .cursor/mcp.json):

{
  "mcpServers": {
    "petriflow": {
      "url": "http://localhost:3001/mcp"
    }
  }
}
VS Code (MCP / Copilot Chat)

Add to .vscode/mcp.json in your workspace:

{
  "servers": {
    "petriflow": {
      "type": "http",
      "url": "http://localhost:3001/mcp"
    }
  }
}
Windsurf

Add to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "petriflow": {
      "serverUrl": "http://localhost:3001/mcp"
    }
  }
}
Other MCP clients

Any client that supports the MCP Streamable HTTP transport can connect directly to http://localhost:3001/mcp — no API key required by default.
